Phase 1 of 5

Manual Craft

The seven lessons where the apprentice writes every line by hand.

In this phase the apprentice writes 100% of the code. The Craftsman never writes Shoddy here — it shows worked examples on different problems, then coaches with questions. The goal isn’t to finish fast; it’s to build the judgment that later lets the apprentice look at code the Craftsman wrote and know whether to trust it.

Two habits run through all seven lessons

  • Predict before you run — never execute blind. Write down what you expect first.
  • The bugs live on the boundaries — first met in Lesson 3, and reappearing in every lesson after.
