Phase 1 of 5

Manual Craft

The seven lessons where the apprentice writes every line by hand.

In this phase the apprentice writes 100% of the code. The Craftsman never writes Shoddy here — it shows worked examples on different problems, then coaches with questions. The goal isn’t to finish fast; it’s to build the judgment that later lets the apprentice look at code the Craftsman wrote and know whether to trust it.

Two habits run through all seven lessons

  • Predict before you run — never execute blind. Write down what you expect first.
  • The bugs live on the boundaries — first met in Lesson 3, and reappearing in every lesson after.
1 Hello, Shoddy Make the computer say something and run your first program. Thinking skill Guess the result before you run. → 2 Values & Names Store numbers and text, name them, and join text together. Thinking skill Keep track of what each name holds. → 3 Decisions Make the code choose between options. Thinking skill List every case; hunt the boundaries. → 4 Doing Things Again Repeat an action — the Shoddy way, with no loops. Thinking skill Describe ‘for every item,’ not each step. → 5 Building Your Own Words Write your own reusable commands (functions). Thinking skill Break a big job into small named pieces. → 6 A Word That Calls Itself Recursion — a function that uses itself. Thinking skill Trust the smaller case; find the stopping point. → 7 Words That Take Words Lambdas and Map / Filter / Fold. Thinking skill Separate what to do from what to do it to. →
