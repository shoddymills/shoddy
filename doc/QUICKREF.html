Shoddy Quick Reference — every word, type, and syntax form

Making useless things useful, through skill.

Case-insensitive; convention is PascalCase for words and types, camelCase for variables. Indexes are 1-based. Everything is immutable — "update" words return new values. Words marked LIB come from machines/ (the standard library) (use Include); all others are built in.

Program structure

FormMeaning
Def Name(p As t, ...) As rFunction, expression-syntax body. Last value = result; no RETURN. Implicit binding of parameters.
Def Name ( a b -- c )Function, concatenative (stack) body; signature is documentation.
Def Main()Entry point.
Type Name ↵ fieldsRecord declaration: indented field As Type lines. Declare before use.
Type Name = v1(f, ...) | v2Sum type: each variant is a constructor/pattern. Bare variant = zero fields (construct as v2()).
Include "FILE.SHODDY"Splice a file (include-once). Resolved relative to the including file, then the SHODDYLIB directory. Left margin.
Rem ...  or  ' ...Comment to end of line.
Let x = exprImmutable binding; one per name. At the left margin: a program-wide constant, evaluated once before Main (the outermost scope).

Indentation is structure. A call must finish on its line; a statement may continue on deeper-indented lines (pipelines). Reserved characters, never in names: ! % # $ ?

Conditionals & matching

If cond Then            Select Case expr
    result                  Case 0                  ' equality
Else                        Case 1, 2, 3            ' any-of
    other                   Case 4 To 10            ' inclusive range
                            Case Is > 10            ' comparison (Is optional)
Ifte(c, t, f)  ' inline     Case Person(n, a) Where a < 18   ' destructure + guard
                            Case Order(Person(n, _), it, t)  ' patterns nest; _ = ignore
                            Case Else               ' default (else non-match aborts)

Both are expressions: each branch/clause block yields the value. Scrutinee evaluates once. Pattern names bind for guard and body; sub-patterns nest to any depth. Case Type(...) is always a pattern; equality vs a record: Case = Type(...) (or bare Case None for a zero-field variant).

isam.shoddy LIB — indexed-sequential files

Binary random-access files

1-based byte positions; GET/PUT advance the position. Fixed field sizes make record offsets computable: Name(12) + Score(8) = 20-byte records, record k at 1 + (k-1)*20.

PutNum(h, n) / GetNum(h)8-byte IEEE double.
PutBool(h, b) / GetBool(h)1 byte.
PutStr(h, s, Len)Fixed Len-byte field, zero-padded; over-length aborts.

Reading past end of file aborts. All effectful, like Print.
