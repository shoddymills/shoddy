Summary

seedclock bridges clock: STAMP STAMPDATE STAMPTIME TICKS ELAPSED FORMATDURATION. Not TimeIt: it takes a quotation, and a bridged word that wants a function is a word that isn't bridged — a combinator covers the case instead. None of TIMES/MAP/FILTER/FOLD answers a duration, so a program reaches for TICKS before and ELAPSED after.

Why It's Useful

Every word here is total: Stamp, StampDate, StampTime and Ticks cannot fail, and FormatDuration is arithmetic and string formatting over whatever number it is given — so this seed carries no guards of its own. STAMP, STAMPDATE, STAMPTIME and TICKS touch the world; FORMATDURATION does not — reading the clock answers something different from one call to the next exactly as reading a file does, while formatting a number already on the stack touches nothing.

User's Guide

Let st0 = RckSeedClock(RckNew())
RckEval(st0, "TICKS")            ' x: milliseconds since the program started
RckEval(st0, "STAMP")            ' x: "2026-08-05T14:03:11.204"
RckEval(st0, "64200 FORMATDURATION")   ' x: "1m 04.2s"

Word Reference

WordDescription
STAMP ( -- s )The current date and time, ISO-8601.
STAMPDATE ( -- s )The current date, YYYY-MM-DD.
STAMPTIME ( -- s )The current time of day, HH:MM:SS.mmm.
TICKS ( -- n )Monotonic milliseconds since the program started; for measuring, not stamping.
ELAPSED ( since -- ms )Milliseconds since the TICKS value since.
FORMATDURATION ( ms -- s )ms written as a duration, e.g. "1m 04.2s".

Who Uses It

No machine or mill includes it yet. A mill claims it by folding RckSeedClock over its reckoner state.
