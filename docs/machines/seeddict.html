seeddict

A reckoner seed: dict over a list of pairs — machines/seeds/seeddict.shoddy

← Previous machineseedmatrixAll machinesseedfileNext machine →

Summary

seeddict bridges DPUT DGET DHAS DKEYS. A "dict" at the keyboard is an ordinary LIST cell whose elements are PAIR cells — no new stack case, the same discipline matrix's seed applies to arrays, applied here to association lists: "rate" 0.05 PAIR 1 GATHER is a one-entry dict, and DPUT grows it.

Why It's Useful

Not delegated to dict.shoddy's own words, on purpose. DictGet, DictHas and DictPut compare keys with the language's native =, which compares a List or a Program cell by identity rather than by value. Keying by CutEqual instead — the same structural equality = already gives every other stack word — is what lets "rate" and a computed { 1 2 } key alike behave the way DUP = already promised they would. DGET is also guarded where DictGet isn't: DictGet Errors on a missing key, and DGET answers a refusal instead, naming the key.

User's Guide

Let st0 = RckSeedDict(RckNew())
RckEval(st0, Chr(34) & "rate" & Chr(34) & " 0.05 PAIR 1 GATHER")   ' x: one-entry dict
RckEval(st0, Chr(34) & "term" & Chr(34) & " 12 DPUT")               ' x: two-entry dict
RckEval(st0, Chr(34) & "rate" & Chr(34) & " DGET")                  ' x: 0.05

Word Reference

WordDescription
DHAS ( d k -- flag )Whether the dict has an entry for key k.
DGET ( d k -- v )The value stored under key k; refuses a missing key, naming it.
DPUT ( d k v -- d )The dict with key k set to v, added if it was not already there.
DKEYS ( d -- list )The dict's keys, in the order they were entered.
