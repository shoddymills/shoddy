seedmoney

A reckoner seed: money's exact currency — machines/seeds/seedmoney.shoddy

Summary

seedmoney bridges money's exact currency: MONEY builds a MONEY cell from a NUMBER of dollars; MADD and MSUB name the same arithmetic the engine core's polymorphic + and - already give money cells, for a dictionary that wants to say what it means; MSPLIT allocates a MONEY into n parts without losing a penny; MFMT is the exact string RckShow already renders a MONEY cell as, for a program that wants the text itself rather than the display.

Why It's Useful

A calculator that only ever prints its own display cannot hand a formatted total to another word — a report line, a saved file, a concatenated string. MFMT is that seam: the same rendering RckShow uses, available as an ordinary value.

User's Guide

Let st0 = RckSeedMoney(RckNew())
RckEval(st0, "1234.56 MONEY")        ' x: $1,234.56
RckEval(st0, "MFMT")                 ' x: "$1,234.56"
RckEval(st0, "1234.56 MONEY 3 MSPLIT")   ' x: { $411.52 $411.52 $411.52 } — no penny lost

Word Reference

WordDescription
MONEY ( x -- money )x dollars, as exact currency to the cent.
MADD ( a b -- a+b )Two MONEY cells added exactly.
MSUB ( a b -- a-b )Two MONEY cells subtracted exactly.
MSPLIT ( m n -- list )m divided into n MONEY shares, no penny created or lost; refuses a share count below one.
MFMT ( money -- s )A MONEY cell formatted as text, e.g. $1,234.56.
