Summary

seedneural bridges neural: NEURALNEW, NEURALPREDICT, NEURALSCALERFIT and NEURALSCALERAPPLY — enough to build a small regression net, scale its inputs and predict, entirely on the stack. Per R4.16 there is no NETWORK cell at the keyboard: a Net is a dict, the same LIST-of-PAIR shape seeddict already established — { ("w1" matrix) ("b1" list) ("w2" matrix) ("b2" list) } — and a Scaler is { ("center" list) ("spread" list) }. NEURALNEW is RckTouch: it draws initial weights from Rnd, so two calls with the same arguments do not answer the same net.

Not bridged: NEURALTRAIN. NetTrain folds an epoch step — which shuffles (random.shoddy) and steps — over epochs, and calling it from a registered word here corrupts the reckoner's own state the moment the fold runs for real; zero epochs, which skips the fold, works fine. That points at an interaction between a quotation invoked through Call deep inside a dictionary word's own dispatch and the engine's state threading, not at this seed's own conversions — a net trained outside halifax still predicts here once its weights are on the stack via NEURALNEW's own shape. Also not bridged: the classification head (NetFit, Softmax, the Plan record and momentum), a second coherent training path deserving its own pass, and every file format (NetSave/NetLoad, NetSaveBin/NetLoadBin, ModelSave/ModelLoad), which go through BOpen/recio directly rather than TRYREADFILE/TRYWRITEFILE.

Word Reference

WordDescription
NEURALNEW ( ni nh no -- net )A new net: ni inputs, nh hidden units, no outputs, small random weights. Refuses unless all three are whole numbers of 1 or more.
NEURALPREDICT ( net x -- y )The net's scalar output for input x.
NEURALSCALERFIT ( xs -- scaler )A scaler that centres and spreads xs's columns to mean 0: a dict with center and spread. Refuses on an empty list.
NEURALSCALERAPPLY ( scaler x -- x2 )x, centred and scaled by scaler. Refuses unless x has as many entries as the scaler was fitted with.
