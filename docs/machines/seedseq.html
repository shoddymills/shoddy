Summary

seedseq bridges list and pair structure: RANGE LENGTH REVERSE CONCAT FIRST REST SORTL work a LIST cell; PAIR HEAD TAIL work a PAIR cell — "rate" 0.05 PAIR gives records on the stack. Most of these are one line over a builtin the language already has (Range, Length, Reverse, Concat, Sort); this seed's job is only to fence off the cases those builtins Error on.

Why It's Useful

SORTL is the one word here that is not a thin wrapper: a Cell is a record, so the Sort builtin — which wants raw Numbers or Strings — cannot see through one. SORTL unwraps a homogeneous list of one kind, sorts the raw values, and wraps the answer back up; a list of anything else — mixed, or a kind that has no order — is refused by name rather than reaching Sort to be Errored on.

User's Guide

Let st0 = RckSeedSeq(RckNew())
RckEval(st0, "1 5 RANGE")                       ' x: { 1 2 3 4 5 }
RckEval(st0, "{ 3 1 2 } SORTL")                 ' x: { 1 2 3 }
RckEval(st0, Chr(34) & "rate" & Chr(34) & " 0.05 PAIR")  ' x: ( "rate" 0.05 )

HEAD and TAIL project a pair back apart, so a program can carry a labelled value without a dictionary:

RckEval(st0, "HEAD")   ' x: "rate"
RckEval(st0, "TAIL")   ' x: 0.05

Word Reference

WordDescription
RANGE ( a b -- list )The whole numbers from a up to b, one cell per value; empty when b is below a.
LENGTH ( list -- n )How many elements a list holds.
REVERSE ( list -- list )The list back to front.
CONCAT ( xs ys -- list )Two lists joined end to end.
FIRST ( list -- x )The first element of a list; refuses an empty list.
REST ( list -- list )The list without its first element; refuses an empty list.
SORTL ( list -- list )A list of numbers or a list of strings, sorted ascending; refuses a mixed list or one whose kind has no order.
PAIR ( a b -- pair )Two cells joined as one record.
HEAD ( pair -- a )The first cell of a pair.
TAIL ( pair -- b )The second cell of a pair.
