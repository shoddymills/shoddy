Shoddy Documentation

Mills

Complete programs, one page per mill

The machines are the library; the mills are the finished cloth — complete, working programs woven from them, each in its own folder under mills/ in the repo. Every mill is meant to be read as much as run: real Shoddy at program scale, showing how a purely functional BASIC handles a game loop, a neural network, or a command-line tool. Each page covers one mill: what it is, where it came from, how to run it, and how it's built.

The mills share one architecture worth knowing before you read any of them: each program splits into a pure core — the state record and every rule of the simulation, including nothing that touches a screen, so it runs headless and is unit-tested that way — and a thin I/O shell that adds the drawing, the prompts, and the loop on top. Every mill folder carries its own build.cmd / build.sh wrapper (same subcommands on both), and each wrapper builds the mill toolchain itself first if bin/ is missing.

Demos

MillWhat it is
devils-dustWool in the air of a shoddy mill — a hundred wisps flocking by the three boids rules above the devil's drum, with a live tuning console (21 sliders, a speed lever that goes to eleven, heat-coloured gauges) and a machine-room drone that rises and falls with the drum.Ready
rag-and-boneAn HTTP server written in Shoddy. The routing is one pure function — request text in, response text out — so every route is graded by calling it, with no socket and no network. The listener is twenty lines beside it.Ready

The language's origin story, animated — and the interactive one: every constant of the simulation is a slider, the presets are lever positions the machine winds to with iron inertia, and the sound is another gauge. This is also the mill whose sound experiments grew the buzzer's SoundWave builtin.

Machine learning

MillWhat it is
irisNeural species classification — a 4-8-3 tanh/softmax net over Fisher's iris data, trained with momentum in about four seconds, reporting a confusion matrix and a probability per species.Ready
demographicsNeural income prediction — the same machine wearing its other head: an 8-100-1 tanh regression, serialized bit-exactly, then predicting interactively from the trained model.Ready

The pair is worth reading together: iris predicts a category, is scored on how often it is right, and says how sure it was; demographics predicts a number and is scored on how close it gets. Same machine, same train-once/predict-many split, different head. Iris trains in about four seconds and demographics in about nine minutes, so iris is the one to reach for first.
