Shoddy Documentation

The Language Specification

Useless Things Made Useful Through Skill

The name is from the shoddy trade of the West Riding of Yorkshire: from 1813 the mills of Batley and Dewsbury tore worn-out rags back to fiber (in a machine called the devil), blended the reclaimed stock with new wool, and wove it into cloth again — until synthetic fibers ended the trade. The language is built the same way: old ideas reclaimed, blended with new wool, woven into something useful. The executable is the mill; the libraries are its machines. The full story is in heritage.html.

Version 1.0.0

Shoddy is a purely functional BASIC. Its surface syntax is typed and applicative — parenthesized calls, infix operators, Let, Fn — and it desugars onto a concatenative (stack-based) core in the tradition of Joy and Kitten. Both styles are legal and mix freely:

Def Hypot(a As Number, b As Number) As Number
    Sqr(Square(a) + Square(b))

Def Square ( Number -- Number )
    Dup *

Pedigree: Kitten’s semantics, BASIC’s keywords, Python’s layout.

1. Philosophy

  • Purely functional: no variables, no assignment, no goto, no mutation. Let binds; it never rebinds.
  • Iteration is recursion or a combinator (Map, Fold, Filter, Each, Times). There is no mutable loop index — for is a mutable index in a trenchcoat, so it doesn’t exist.
  • Every definition compiles to a pure stack-to-stack function. The stack is the compilation target; most programs never mention it.
  • Layout is structure: indentation delimits bodies and branches. No endif, no end def, no ;, no line numbers.
  • Effects live at the edge: by convention Print appears only in Main.

2. Lexical structure

  • Case-insensitive — the mill folds case entirely, so Map, MAP, and map are the same word. Convention: PascalCase for keywords, types, functions, and field accessors (Def, Number, MatMul, Score); camelCase for variables and parameters (xs, bestRatio). Records print back in their declared spelling.
  • Self-delimiting characters: ( ) { } [ ] , — everything else splits on whitespace.
  • Numbers: 42, -3, 1.5 (IEEE double).
  • Strings: double-quoted, single line. Escapes: \" \\ \n \t \r.
  • Comments: Rem or ' to end of line.
  • Line continuation: a line whose brackets are still open continues onto the next physical line — wrap long calls after a (, {, [, or any comma inside them. Continuation lines carry no indentation meaning; comments and blank lines may appear mid-continuation. Any long expression can be made wrappable by parenthesizing it. A Def at the left margin always starts a new function, so a missing close bracket is reported at the line that opened it.
  • Reserved characters: BASIC’s type sigils ! % # $ and the predicate suffix ? may not appear in words. Types live in declarations, not names. Predicates use the Is prefix (IsEmpty, IsEven) after Visual BASIC’s IsEmpty/IsNumeric; string words are de-sigiled (Str, Mid, Left), matching Val and Asc which never had a sigil.

4. Definitions

Three header forms, dispatched by shape:

Def Name(p As t, ...) As r      ' applicative body (expression syntax)
Def Name ( t ... -- u ... )     ' concatenative body, effect signature
Def Name                        ' concatenative body, undocumented effect

Applicative parameters perform an implicit Take; the body is a sequence of statements whose final value is the result. Def Main() is the entry point. A fourth top-level form, Let NAME = expr at the left margin, binds a program-wide constant: all top-level Lets are evaluated once, in textual order, before Main, each seeing earlier ones and any Def. They form the outermost lexical scope — visible in every body, closed over by quotations, immutable like every binding. (No separate Const keyword: a Let that can never rebind already is one.)

5. Expressions (applicative bodies)

  • Calls: f(a, b) desugars to a b f — arguments load left to right, then the word runs.

  • Infix operators, low to high precedence: Or; And; comparisons = <> < > <= >=; `+ - &;* / Mod;^(right-associative, so2 ^ 3 ^ 2is 512 and-n ^ 2is-(n^2), as in classic BASIC).Notand unary-` are prefix. Parentheses group.

  • And and Or short-circuit in expression bodies: the right side evaluates only when needed, so Not IsEmpty(xs) And First(xs) > 0 is safe on an empty list. (The core’s postfix And/Or words remain strict — both operands are already on the stack by then.)

  • Let Name = expr binds an immutable local for the rest of the body.

  • Pipeline chaining: adjacency is stack flow. A call may consume the value of the preceding expression, and deeper-indented lines continue a statement:

    Def EvenSquareSum(n As Number) As Number
    Range(1, n)
        Filter(IsEven)
        Map(Square)
        Fold(0, +)

  • Conditionals: If cond Then with indented branches; Else alone on a line at the If’s indent. If is an expression — each branch’s final value is its result. Inline alternative: Ifte(cond, t, f).

  • Select Case — QBasic’s value matching, as an expression. The scrutinee evaluates exactly once; the first matching clause’s block is the result. Clause forms: Case expr (equality), Case e1, e2, ... (any-of), Case a To b (inclusive range), Case [Is] >= expr (any comparison operator), Case Type(n1, ..., nk) [Where cond] (record destructuring: matches records of that Type, binds every field in declaration order to the given names — in scope for the guard and the body), and Case Else (default, last). With no Case Else, a non-match is a runtime error. Desugars to nested Ifte over a hidden one-time binding. Note Case Type(...) is always a pattern; to test equality against a constructed record, write Case = Type(...).

    Def Greet(p As Person) As String
    Select Case p
        Case Person(n, a) Where a < 18
            "HEY " & n
        Case Person(n, a)
            "HELLO, " & Upper(n)
    Def Grade(score As Number) As String
    Select Case score
        Case >= 90
            "A"
        Case 80 To 89
            "B"
        Case Else
            "F"

6. Function values — where the brackets went

A quotation is deferred code; brackets are the core’s quote marker. In the applicative surface they’re rarely needed:

  1. Bare names auto-quote in argument position. A name that isn’t a local binding is passed as a function value: Fold(xs, 0, +), Map(xs, Square), Filter(xs, IsEven). To force a bare name to evaluate instead, parenthesize it: f((g)).
  2. Sections pre-load an operator’s trailing arguments: Filter(xs, >=(100)) — “≥ with 100 pre-loaded” — instead of [ 100 >= ].
  3. Fn lambdas for anything genuinely inline: Filter(xs, Fn(x) => x Mod 2 = 0). Sugar for a quotation beginning with an implicit Take.
  4. [ ... ] remains legal everywhere as raw core code, and is required inside concatenative bodies, where without the quote marker If’s branches would run before If did.

Call applies a function value: Call(f, acc, x) ≡ acc x f Call.

Quotations are closures. A function value captures the environment where it was created (lexical scoping): Filter(xs, >=(p)) still sees p when a library word executes the quotation later. Since bindings are immutable, capture costs one pointer.

7. Lists

{ 1, 2, 3 } builds a List Of Number; elements are arbitrary expressions, evaluated at construction. Lists are immutable.

Primitives: IsEmpty First Rest Prepend. Library (expressible in the language itself): Map Filter Fold Each Times Range Length Reverse Concat Call Ifte — provided as builtins for speed, self-hostable as:

Def MySum(xs As List Of Number) As Number
    If IsEmpty(xs) Then
        0
    Else
        First(xs) + MySum(Rest(xs))

8. Records: Type

QuickBASIC’s record syntax, minus the end Type that layout makes redundant. Declared at column 0, before first use:

Type Person
    Name As String
    Age  As Number

Declaring a Type generates three things:

  • A constructor word, positional or named (not mixed): Person("ANN", 34) or Person(Name = "ANN", Age = 34). Positional arity is checked at parse time.
  • Accessor words for each field: Name(p), Age(p). Accessors are ordinary words, so they compose with everything: Map(people, Name), Filter(people, Fn(p) => Age(p) >= 18), and in the concatenative core simply p Age. Two TYPEs may share a field name; the accessor dispatches on the record’s tag at runtime. (Don’t name fields after builtins — the builtin wins.)
  • Functional update via With, returning a new record: With(p, Age = Age(p) + 1) — any number of field = value pairs.

Records are immutable, compare structurally (=), nest freely (Customer As Person), and print as valid input: Person(Name = "ANN", Age = 34).

Sum types declare tagged alternatives on one line:

Type Shape = Circle(r) | Rect(w, h)
Type Option = Some(v) | None

Each variant is a full record type — constructor, accessors, With, patterns — and Select Case dispatches on the variant:

Def Area(s As Shape) As Number
    Select Case s
        Case Circle(r)
            Pi() * r ^ 2
        Case Rect(w, h)
            w * h

A bare variant (None) has zero fields; construct it as None() (or bare None outside argument position) and match it with Case None (structural equality) or Case None(). Option is the language’s answer to NULL: absence is a value you must match, never a hole.

Patterns nest. A sub-pattern may be a binder name or another Type(...) pattern, to any depth; _ is an ordinary binder used by convention for ignored fields:

Select Case o
    Case Order(Person(n, _), items, total) Where total > 100
        n & " (BIG SPENDER)"

9. Arrays

List is the inductive type — cheap First/Rest/Prepend, made for structural recursion. Array is the indexed type — fixed length, immutable, O(1) Nth, functional SetNth (returns a new array). Use lists to recurse, arrays to index; matrices are arrays of arrays.

Let a = ToArray(Range(1, 5))    ' Array(1, 2, 3, 4, 5)
Nth(a, 3)                       ' 3, in o(1)
SetNth(a, 3, 99)                ' Array(1, 2, 99, 4, 5) — original untouched
Dim(3, 0)                       ' Array(0, 0, 0) — basic's keyword, reclaimed

Map Filter Fold Each Length IsEmpty First Nth SetNth Reverse Concat Sort are polymorphic over both kinds and preserve the input’s kind (Map over an array yields an array). ToArray/ToList convert. Rest/Prepend stay list-only by design — on an array they’d hide an O(n) copy.

12. Tail calls and errors

Tail recursion is the language’s loop (the mill compiles self-tail-recursion to a loop, so the Fact-with-accumulator shape runs in constant stack; mutual recursion still consumes stack). Runtime errors — stack underflow, type mismatch, unknown word, division by zero — abort with a message and source line number.

13. Include and the standard library

Include "FILE.SHODDY" at the left margin splices another source file in at that point — include-once semantics. Resolution: relative to the including file first; if not found there, the directory named by the SHODDYLIB environment variable. The fallback lets a deployed mill carry the standard library anywhere (set SHODDYLIB to the repo's machines/ and Include "seq.shoddy" works from any folder). When compiling, an include resolves to a prebuilt machine DLL (Shoddy.Machines.Seq.dll beside the source) if present, else splices the source. Declarations must precede use, so libraries go at the top.

The standard library is written in Shoddy itself:

  • seq.shoddy — the Fold/Map usual suspects, structure only: Any All CountIf Contains IndexOf Taken DropN Append Last Flatten Zip ZipWith, plus Type Pair (Fst/Snd). Aggregation lives in stats.shoddy; sorting is the Sort builtin.
  • matrix.shoddy — Type Matrix over a flat row-major array (O(1) MatGet, dimension-checked ops via Error): Mat MatFill Ident MatFromRows MatGet MatSet MatRow MatCol Dot VAdd VSub VMul VScale Outer MatMul MatAdd MatSub MatScale Transp MatVec MatShow (VMul is elementwise; Outer is the outer product). Includes seq.shoddy.
  • str.shoddy — Split Join Trim Replace StartsWith EndsWith StrRep, built on the Instr/Left/Right/Mid builtins.
  • money.shoddy — exact currency as Type Money over whole cents (exact past $90 trillion in a double; no DECIMAL type needed): Dollars MoneyVal MoneyAdd MoneySub MoneyMul (explicit rounding) MoneySum MoneyLt MoneySplit (penny-preserving allocation) MoneyFmt.
  • file.shoddy — line-oriented text files over the whole-file builtins: ReadLines (normalizes \r\n, drops the trailing newline), WriteLines, AppendLine. Includes str.shoddy.
  • recio.shoddy — record-oriented binary I/O: give it a record size and a reader/writer function and it does the offset arithmetic. RecPos RecSeek RecCount GetRec PutRec AppendRec AllRecs (records numbered from 1).
  • dict.shoddy — dictionaries as association lists (List Of Pair); keys compared with = so any equatable value works. DictPut DictGet DictGetOr DictHas DictDel DictKeys DictVals. Pure; a hashed implementation could replace it behind the same words.
  • stats.shoddy — statistics, pure Shoddy over the Erf/GammaP/BetaI and Sort builtins. Descriptive: Sum Product Maximum Minimum Mean (Average is an alias) WeightedMean GeoMean HarmonicMean Median Quantile Percentile Iqr RangeOf Var VarP StdDev StdDevP StdErr Mad Skewness Kurtosis ZScore ZScores Outliers OutliersZ Freq RelFreq Modes Ecdf Cov Correl Spearman LinFit (→ Fit). Distributions: NormPdf NormCdf Chi2Cdf TCdf FCdf NormInv TInv. Inference (all → TestResult(Stat, Df, PVal), two-sided): TTest1 TTest2 TTestPaired ZTest1 Anova ChiSqGof ChiSqTest TwoPropZTest, plus MeanCI PropCI (→ Pair) and CohenD. Sample forms divide by n−1; quantiles interpolate (R type 7). Includes seq.shoddy and dict.shoddy.
  • isam.shoddy — indexed-sequential files: fixed-length records with a 1-byte tombstone flag per slot, plus a key→slot index kept on disk as a B+tree in a companion file (path & ".idx": header with root page, live count, and free-list head; the free list threads through dead slots' payload bytes). Opening reads the header — O(1), no scan — falling back to a one-time rebuild scan only when the index file is missing; index entries hold slot numbers and keys are re-derived through KeyOf, so Number and String keys both work with no width limit. Mutating words still return the handle (unchanged — it carries only the two file handles and your functions). Keys via a user KeyOf function; deletes free slots for reuse. IsamOpen IsamClose IsamInsert IsamUpdate IsamDelete IsamGet IsamGetOr IsamHas IsamCount IsamAll IsamRange IsamFirst IsamLast IsamNext IsamPrev. Sequential access is cursorless (key-order navigation). No crash safety or concurrency; one live handle at a time.
  • math.shoddy — the derived math layer over the numeric builtins: E Tau Rad Deg Angle Frac RoundTo Clamp Lerp InvLerp Remap Smoothstep Hypot Dist Log2 LogBase, plus game-flavored randomness RandRange RandInt Pick Chance. Pure except the random words.
  • random.shoddy — random numbers over the Rnd builtin, seedless by construction: Random RandomRange RandomInt Shuffle Sample (without replacement, capped at the length). Impure, like Rnd itself.
  • neural.shoddy — feed-forward neural networks: one hidden Tanh layer, identity output, mini-batch SGD regression on squared error. Type Net (W1 B1 W2 B2 — a gradient has the same shape, so NetAdd/NetScale do all accumulation and updating) and Type NetEval (Hidden Output): NetNew NetEvalAt NetOut NetGrad NetStep NetTrain NetMse NetAccuracy NetSave NetLoad NetSaveBin NetLoadBin NetWeightList NetFromList. Two formats over one canonical (input-major) weight order: text, one number per line, C#-interchangeable; and binary over recio — a self-describing header (magic, ni, nh, no) then raw 8-byte doubles, so NetLoadBin(path) takes no architecture arguments and round trips are bit-exact. Impure at exactly two edges (NetNew's initialization, NetTrain's per-epoch shuffle — Seed once for reproducible runs); classroom scale. Includes matrix.shoddy, random.shoddy, file.shoddy, and recio.shoddy.
  • clock.shoddy — timing over the Ticks/Sleep/Clock builtins: monotonic measuring (Elapsed TimeIt SleepUntil) and wall-clock stamping (Stamp StampDate StampTime DateOf TimeOf, ISO-8601 shapes) plus FormatDuration.
  • vt100.shoddy — VT100 terminal escape codes: every word returns the escape string (nothing prints itself) — cursor movement, SGR attributes, clearing, scroll regions, character sets, VT52 mode, the full DEC private-mode set/reset pairs — plus Type Vt100Key and EvalKey(raw) to classify keystrokes from InKey().
  • keys.shoddy — physical-key classification for scribbler programs: Type GameKey (ArrowLeft…ArrowDown SpaceBar EnterKey EscKey TabKey BackKey CharKey(Code) OtherKey(Code)), ClassifyKey (a ScribblerKeyDown code → GameKey), KeyGlyph, IsKey.
  • simplex.shoddy — linear programming: Problem(Costs, A, Rhs) (minimize Costs·x subject to Ax ≥ Rhs, x ≥ 0), Optimize → Solution(Status, X, Cost, DualPrices, Reduced, Iterations) — shadow prices and reduced costs included. Revised simplex over the matrix machine, solved via the dual, big-M artificials only when negative costs require them. Honest statuses: OPTIMAL UNBOUNDED INFEASIBLE MAXITER UNBOUNDED-OR-INFEASIBLE. Pure. Includes matrix.shoddy.
  • mps.shoddy — reading MPS linear-programming files, the industry interchange format that feeds simplex: ParseMps LoadMps → Problem; ParseMpsModel LoadMpsModel → MpsModel (the Problem plus variable and constraint names); …ZeroLower variants pin free variables at zero. Includes str.shoddy and simplex.shoddy.
  • scribbler.shoddy — the friendly layer over the scribbler builtins: Type ScribblerEvent (ScribblerNone MouseDown/Move/Up KeyDown/Up Typed Tick Quit — all constructors Scribbler-prefixed against vt100's KeyUp/KeyDown, every kind carrying an At timestamp), NextEvent (blocks at zero CPU) / PeekEvent / DecodeEvent, frame timing SetFps SinceLast, and shapes over the one pixel primitive: DrawHLine DrawVLine DrawLine (Bresenham) DrawRect FillRect DrawCircle FillCircle (midpoint) DrawPolyline DrawPolygon (Type Point) FloodFill (scanline, worklist — no recursion depth). Every drawing word returns the scribbler. Includes seq.shoddy and clock.shoddy.
  • turtle.shoddy — purely functional turtle graphics drawing into a scribbler: Type Turtle threaded through NewTurtle Home Blit Close Title Forward Back TurnLeft TurnRight SetHeading SetXY MoveTo SetTowards DistanceTo PenUp PenDown SetPenColor. Heading is degrees, 0 = up, clockwise positive — the turtle convention — over the scribbler's own pixel coordinates; Home is the window center; position stays fractional so polygons close. Includes scribbler.shoddy and math.shoddy.
  • plotter.shoddy — statistical charts, stats doing the arithmetic and scribbler the drawing: NewPlot PlotTitle Histogram BarChart PieChart BoxPlot ScatterPlot, with the lower level exposed (Palette PlotColor DrawAxes XLabels YLabels ScaleTo BinCounts) for custom charts. Includes scribbler.shoddy and stats.shoddy.
  • buzzer.shoddy — sound: note names, MIDI numbers, and a GW-BASIC-subset MML player over the sound builtins (Sound NoteOn NoteOff SoundQueue SoundStop SoundGain, channels 1–8; audible under mill run/mill dap, a silent no-op headless — bad arguments raise even in silence). Type BuzzerNote (FreqHz/Ms; 0 = rest), MidiFreq NoteMidi NoteFreq MmlNotes (pure: MML string → note list) Play PlayNotes. The frequency word is MidiFreq, never Freq — stats.shoddy owns FREQ. Includes seq.shoddy.

Appendix A. The concatenative core

The compilation target is itself a legal, complete language: Joy with BASIC vocabulary and layout. Every word is a pure Stack → Stack function; composition is juxtaposition. (This appendix is the law; the tutorial companion — worked traces, the stack drawn after every word — is The Stack.)

Def Fact            Rem ( n -- n! )
    Dup 0 =
    If Then
        Drop 1
    Else
        Dup 1 - Fact *
  • Items on a line execute left to right; lines top to bottom.
  • If (optionally If Then) ends its line, pops a Boolean, and runs one of the two indented branches — sugar for [ then ] [ else ] Ifte. Tokens before If on the same line execute first: Dup 0 < If Then.
  • Take a, b, c pops into immutable named bindings (topmost value goes to the rightmost name) — the escape hatch from Swap Rot Dup shuffle-hell, cf.Â Factor’s :>.
  • [ ... ] quotes code without running it. Combinators (Map, Fold, Call, Ifte, …) execute quotations.
  • A quotation of literals doubles as a list (Joy-style homoiconicity); the typed surface’s { } lists compile to exactly this.
  • Stack-effect comments Rem ( a b -- c ) or signatures Def f ( a b -- c ) document (and eventually check) each word.

Appendix B. Design notes

  • Why no sigils? a%/a# were the type system of a language without declarations; As types make them a second, contradictable spelling of the same fact, and no sigil exists for List Of t or a generic return. ! (mutation, in the Scheme/Ruby reading) is banned by semantics — reserving it is the most purely functional decision available.
  • Why layout-as-quotation? Indented branches compile to quotations. Newcomers read structured BASIC; the machine sees Joy. Nobody has to know.
  • Why keep the core exposed? Point-free pipelines (data Filter(p) Map(f) Fold(z, g)) are often the clearest notation, and the desugaring rules stay honest when the target is a language you can actually write.
  • Line numbers existed for editing and goto; both are gone.
