Shoddy is a purely functional BASIC. A friendly typed surface — parenthesized calls,
infix operators, `Let`, records, `Select Case` pattern matching — compiled onto a
concatenative (Forth/Joy-style) stack core that remains a legal dialect of the
language. Python's layout, BASIC's keywords, Joy's soul.

This is the first public release.

```basic
Include "machines/stats.shoddy"

Type Student
    Name  As String
    Score As Number

Def Grade(s As Student) As String
    Select Case Score(s)
        Case >= 90
            "A"
        Case 70 To 89
            "B-ISH"
        Case Else
            "F"

Def Main()
    Let class = { Student("ADA", 96), Student("LIN", 78) }
    Each(class, Fn(s) => Print(Name(s) & ": " & Grade(s)))
    Print(Average(Map(class, Score)))
```

## What makes it different

**Nothing mutates.** `Let` binds once. "Updates" return new values. There is no
assignment, no `goto`, and no `for` — iteration is recursion and `Map`/`Filter`/`Fold`,
with `Print`, `Input` and `Rnd` kept at the edges by convention.

**There is no NULL.** Variant types make "maybe nothing" a value you pattern-match
rather than a check you can forget. `Select Case` matches values, ranges (`4 To 10`),
comparisons (`Is >= 90`), and destructures records and variants, with `Where` guards.
Records generate an accessor function per field, so `Score` composes like any other
function — `Map(class, Score)`. Booleans are not numbers.

**The friendly syntax is sugar, and the sugar is honest.** These are the same program:

```basic
Def Square(n As Number) As Number
    n * n

Def Square ( Number -- Number )
    Dup *
```

**It is compiled the whole way down.** Every program is woven to C# and compiled with
Roslyn — in memory with `mill run`, or to an assembly on disk with `mill weave` — with
tail-call optimization, separately compiled library machines, and a self-hosted
standard library. The conformance suite is graded byte-for-byte against golden output.

## What's in the box

**The mill** — compiler and runtime — plus a VS Code extension with highlighting,
snippets, debugging and build commands.

**22 machines**, the standard library: `seq` `str` `math` `matrix` `stats` `random`
`neural` `money` `file` `recio` `dict` `isam` `net` `simplex` `mps` `clock` `vt100`
`keys` `scribbler` `turtle` `plotter` `buzzer`. Graphics, sound, record I/O and a
linear-programming solver included. Network access is a gated capability — the socket
words stay shut until you pass `--allow-net`.

**Seven complete programs**, each split into a headless, unit-tested pure core and a
thin I/O shell:

| | |
|---|---|
| `mungo-caverns` | The showpiece — Colossal Cave Adventure with no mutable state anywhere. The travel table is Shoddy source, the rule modules return what happened, and the turn loop decides what gets said. |
| `oregon` | An overland-trail game, after MECC's 1971 original. |
| `pac-vt100` · `invaders` | A VT100 maze chase and a fixed-gun shooter. |
| `demographics` · `iris` | Neural networks — an income regression, and a species classifier that trains in about four seconds. |
| `simplex-from-mps` | A linear-programming solver that reads MPS files. |

## Install

The VS Code extension carries its own mill and the whole machine library, so it is the
entire install. Grab the `.vsix` below and:

```
code --install-extension vscode-shoddy-1.0.1.vsix
```

The only prerequisite is the [.NET 10 runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
— the runtime, not the SDK. Nothing to clone, nothing to build, no environment to set:
a bare `Include "seq.shoddy"` resolves in any folder you open.

To work on the language itself, see
[Build from source](https://github.com/shoddymills/shoddy#build-from-source).

## Where it stands

This is version 1.0, and the toolchain is real: the programs in `mills/` are not
syntax demonstrations but complete, working software, and the conformance suite grades
every one of them byte-for-byte.

Shoddy is also young, and there is work still ahead. Type annotations are parsed and
enforced at runtime; **static checking with stack-effect inference is the headline item
of future work**, alongside a REPL and catchable errors. Errors carry source line
numbers, and `Assert` and `Error` are built in.

Feedback on the design is genuinely welcome —
[Discussions](https://github.com/shoddymills/shoddy/discussions) is the place for it.

## Why "Shoddy"

The name comes from the 19th-century *shoddy* trade of West Yorkshire: mills that tore
worn-out rags back to fiber and rewove them into new cloth. Shoddy is built the same
way — old ideas reclaimed and rewoven, BASIC and Forth and Joy and ISAM among them. The
executable is the mill; the libraries are its machines.

**Useless things made useful through skill.**
