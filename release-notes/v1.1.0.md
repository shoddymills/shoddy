Shoddy is a purely functional BASIC, compiled the whole way down to .NET. This
release adds an eighth mill — the language's own name-story, animated — and gives
the standard library the conversion guards and number formatters BASIC never
quite delivered.

## The new mill: Devil's Dust

"Devil's dust" was the airborne fibre that filled a shoddy mill, thrown off by
the *devil* — the toothed drum that tore rags back into wool. `devils-dust`
models that air: a hundred wisps of wool flocking by Craig Reynolds' three
boids rules while the drum turns below, every frame a pure function of the
last one. No mutation anywhere; the flock is a value.

It comes with a live tuning console — twenty-one sliders on four tabs, each
clamped to its rails, driving a machine that *winds* toward its levers the way
tons of 1875 iron on a belt drive would. The speed lever runs SLOW, NORMAL,
MAX — and ELEVEN, a quarter past every rail, where the gauges burn ember.
The red bar is the emergency stop: the belt comes off, the drum coasts down,
and the wool rains out of the sky.

The devil is heard as well as seen: a polyphonic drone whose pitch climbs as
the belt loads and dies away on a stop coast, built from a detuned sine pair,
a crossfaded overload voice, and a churn locked to the drum's revolutions.
The new `SoundWave` builtin gives the buzzer triangle and sine voices, and
`sound-lab.shoddy` — the workbench the drone was designed on — ships alongside.

Like every mill, the model is a headless, unit-tested pure core with a thin
window shell on top. [Watch it run](https://shoddymills.github.io/shoddy/mills/devils-dust.html).

## Conversions and formatting, reclaimed

`Val` stops the program on a non-number — by design. It now has guards,
built in beside it and sharing its parser so they can never disagree:

- `IsNumeric(s)` — true exactly when `Val(s)` would succeed.
- `ValOr(s, fallback)` — the total conversion. Deliberately *not* GW-BASIC's
  silent `VAL("junk") = 0`: the default is spoken aloud.

The boolean side lives in `str.shoddy`: `IsBool` / `Bool` are the strict
family (TRUE or FALSE, any case, trimmed; `Bool` stops on anything else), and
`BoolOr` also speaks the prompt vocabulary — T/Y/YES/1 and F/N/NO/0 — so a
`(Y/N)?` question is one word.

And the formatters every mill had been hand-rolling are now the library's:

| | |
|---|---|
| `PadLeft` / `PadRight` | Space padding that never truncates. |
| `PadZero(x, n)` | `"07"` — the sign rides outside the padding. |
| `ToFixed(x, p)` | Exactly `p` decimals — `"0.40"`, never `"0.4"`; `p = 0` is the whole-number form. |
| `Commas(x, p)` | `PRINT USING "##,###.##"` as a word: `1,234,567.89`. |

The mills put them straight to work: Devil's Dust dropped its private
formatters, iris and demographics guard their prompts with `IsNumeric`,
`MoneyFmt` learned thousands (`$1,234,567.89`), and clock and money — which
once collided over twin private `Pad2` helpers — now share `PadZero` and can
be included together bare.

## Fixed

- The Devil's Dust SPEED gauge burned ember at a working NORMAL: a leftover
  numeric knob id from before the panel's sum-type conversion fell silently
  to `Case Else` and read the wrong rail. Found by review, not by the
  runtime — which is why static checking stays the headline future-work item.
- Panel manners: clicking a knob's *name* now selects it without slamming its
  value; hiding the panel mid-drag no longer leaves an invisible slider live;
  the footer's `ToFixed` keeps its minus sign.
- The editor grammar learned five builtins it was missing — the two new ones,
  plus `TryWriteFile`, `InputLine`, and `InKey`, which had drifted.
- The README's install command is version-proof (`vscode-shoddy-*.vsix`).

## The documentation grew up

Every machine and mill now carries its identity: pictogram icons on the
catalogs, mastheads, and uses tables, and screenshots on the mill pages. The
two showpieces — Mungo Caverns and Devil's Dust — play as recorded GIFs at
full width on the README and the site's front door.

Two questions now have verified answers on every page. Each mill page's
"The Machines It Uses" table was reconciled against a sweep of every source
file against every machine's word list — and each of the twenty-two machine
pages gained the mirror section, "Who Uses It": the machines that include it
and the mills that call its words, each with one line of how.

## Install

The VS Code extension carries its own mill and the whole machine library, so
it is the entire install. Grab the `.vsix` below and:

```
code --install-extension vscode-shoddy-*.vsix
```

The only prerequisite is the [.NET 10 runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
— the runtime, not the SDK. Upgrading from 1.0.x: install over the top; your
settings survive.
