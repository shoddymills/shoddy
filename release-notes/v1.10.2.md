Fixes forward from v1.10.1, whose tag shipped but whose Release workflow
failed — nothing was published under that version.

## Fixed

- **`TryBOpen` opened files with the default `FileShare.Read`, which
  Windows enforces but Unix does not.** .NET's cross-platform file-share
  emulation only backs a share mode with an OS-level lock (`flock()`) when
  it is `FileShare.None` — anything looser, including the default, goes
  unenforced on Linux and macOS. The result: `seedrecio.shoddy`'s
  `RECOPEN` could be called twice on the same path from two different
  names on a Linux runner, where the same sequence correctly refused on
  Windows. `TryBOpen` now opens with `FileShare.None` explicitly, so the
  refusal is consistent on every platform.

## Changed

- **`seedscribblertest.shoddy`, `seedturtletest.shoddy` and
  `seedplottertest.shoddy` are no longer part of `build.sh test` / CI /
  the release build.** All three open a real window (hidden via
  `--no-window`, but real), and GitHub's hosted runners have no window
  platform for GLFW to attach to — not even under a virtual display
  (`Xvfb`, tried in the abandoned v1.10.1 tag; still failed, most likely
  missing X11 client libraries the bundled GLFW binary itself depends on).
  The suites still exist and still pass on a machine with a real display:
  run them by hand with `bin/mill --no-window run
  tst/seedscribblertest.shoddy` (and the turtle/plotter equivalents).
