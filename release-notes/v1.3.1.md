Shoddy is a purely functional BASIC, compiled the whole way down to .NET. This
is a presentation release: the project gets its **mark, its typeface, and the
trade's own colours**, and the extension gets an icon at last. Nothing in the
language, the compiler, or the machines changed — the mill is byte-for-byte the
one that shipped in 1.3.0.

## The mark

Three threads enter loose from three directions — rag stock, tangled and
unsorted — and from about the two-fifths mark run woven, over and under, into
one continuous plait. It is the shoddy process itself, drawn in a single line,
and it now appears in the topbar of every documentation page, as the favicon,
and at the head of the README.

[The heritage page](https://shoddymills.github.io/shoddy/heritage.html#the-mark)
explains it, and names the colours.

## Unbleached wool

The site is no longer on white. Reclaimed fibre could never be bleached, only
dyed darker, so white was the one colour the West Riding never had; the ground
is now unbleached wool, cards lift from it, and code recesses into it.

The three thread colours are the district's staples — **madder oxblood**
`#6E3A33`, **drab olive** `#55604A`, **indigo navy** `#2F4560` — and they are
also a shade of R, a shade of G and a shade of B: the primaries of the new loom,
dyed in the old lots. Syntax highlighting now wears them, so every code sample
on the site is written in the three threads.

Every ink was checked against the ground it actually sits on and clears
WCAG&nbsp;AA — body text at 12:1, links at 7.7:1, syntax tokens from 4.7:1 to
7.8:1. That included repairing a pre-existing failure: the comment colour had
been sitting at 2.7:1, below the threshold, and is now legible without losing
its recession.

Page titles are set in **Besley SemiBold**, a Clarendon revival — the slab the
Victorian mill trade actually printed in, and the face the wordmark is drawn
from. It ships as a 17&nbsp;KB latin subset; body copy stays on the system
stack.

## The extension has an icon

`vscode-shoddy` had no marketplace icon and showed VS Code's grey default in the
extensions list. It now carries the mark.

## Also in this release

- **Setup page.** A CSS class collision made the whole body of
  [the setup page](https://shoddymills.github.io/shoddy/setup.html) render
  uppercase and bold. Fixed.
- **`lang="en"` everywhere.** Three pages declared an *empty* language, which
  tells assistive technology the language is unknown rather than unset.
- **One head shape.** Three different `<head>` boilerplates were in circulation
  across the site; they are now one, so a new page copied from any existing one
  inherits the same thing.
- **Every image responds to the pointer** — the lift the gallery cards always
  had now covers catalog thumbnails, cross-reference icons and masthead icons,
  with keyboard focus states and a reduced-motion guard.

## Install

The VS Code extension carries its own mill and the whole machine library, so it
is the entire install. Grab the `.vsix` below and:

```
code --install-extension vscode-shoddy-*.vsix
```

The only prerequisite is the [.NET 10 runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
— the runtime, not the SDK. Upgrading from 1.3.0: install over the top. No
program that compiled before will compile differently now.
