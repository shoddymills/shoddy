TLS, an HTTP client, and two mills that prove them — a web server written in
Shoddy, and a weather report in VT100. Additive throughout: nothing that
worked in 1.4.0 has changed.

## Added

- **`TCPSECURE ( h host -- )`** — upgrades a connected socket to TLS in
  place. Gated by the same `--allow-net` as the rest of the socket family:
  it is more network, not a new capability. The host you pass drives both
  SNI and certificate name validation, so it must be the name the
  certificate was issued for.

- **`machines/https.shoddy`** — an HTTP client over TLS, built on `net`.
  **Pure where it can be**, which is the design rule: `HttpRequestText`,
  `HttpStatus`, `HttpReason`, `HttpHeaders`, `HttpHeader`, `HttpBody` and
  `HttpHead` touch no socket and need no `--allow-net`. Only `HttpsGet` and
  `HttpsRequest` reach the network. Headers come back as a `List Of Pair`
  with names lowercased, so `DictGetOr` reads them unaided.
  [https](https://shoddymills.github.io/shoddy/machines/https.html)

- **`net.shoddy` gains the TLS transport** — `Secure`, `ConnectTls`,
  `RecvAllTls`, `RequestTls`, and `WaitRecvFor` for a peer that may never
  close. It now includes `seq` and `str`.

- **`mills/rag-and-bone/`** — an HTTP server written in Shoddy. The whole
  server is one pure function, `Respond(request) -> response`, so every
  route is graded by calling it with a string: no network, no
  `--allow-net`, no server running. The listener is twenty lines beside it.
  [rag-and-bone](https://shoddymills.github.io/shoddy/mills/rag-and-bone.html)

- **`mills/weather-glass/`** — give it a US ZIP and it draws 72 hours off
  the National Weather Service in VT100, banded for day and night with a
  marker at each sunrise and sunset. Sunrise and sunset are **computed**,
  not fetched: the NOAA solar algorithm in forty lines over `math`'s `Rad`
  and `Deg` and the trig builtins, graded to within two minutes of
  published values.
  [weather-glass](https://shoddymills.github.io/shoddy/mills/weather-glass.html)

## Changed

- **A secured socket blocks, and that is deliberate.** Once TLS records
  wrap a stream, a TCP-level poll stops telling the truth about plaintext:
  a partial record makes bytes look ready that decrypt to nothing yet, and
  a fully buffered record makes plaintext look absent when a read would
  return it at once. So on a **secured** handle `Recv` blocks and returns
  `""` only at end of input, `Eof` reads a flag, and **`Ready` is refused**
  — it aborts rather than answer dishonestly. Plain sockets are exactly as
  they were: the never-blocks contract they were built on is untouched, and
  a game loop on the loopback keeps it.

- `RecvAll` no longer accumulates with `chunk & RecvAll(...)`, which was
  quadratic in the reply and not tail-recursive either. Same behaviour,
  different asymptotics.

- The machines catalog gains a **Networking** neighbour: 27 machines now.

## Fixed

- **The linter was lying about a common, correct shape.** A `Def` that
  turns a Number *into* a sum type —

  ```
  Def Classify(t As Number) As Band
      Select Case t
          Case Is < 10
              Cold()
          ...
  ```

  — was reported at every literal call site as "this call always falls to
  `Case Else`", while the program printed `Cold()`, `Mild()` and `Warm()`
  from three different branches. The rule now holds to: a constructor word
  is evidence only where a pattern can appear, never in a result position.
  Genuine matches against constructors still warn, and four regression
  tests guard both directions. Found by the apprenticeship curriculum
  against its own capstone.

- Three `Let df` bindings in `stats.shoddy` (`TTest1`, `TTest2`,
  `ChiSqTest`) shadowed `TestResult`'s `Df` accessor. Renamed; the golden
  output was byte-identical, so nothing computed differently — it was a
  trap waiting rather than a wrong answer.

- The last nullable warning in the compiler is gone. The tree builds with
  **0 warnings**.

- `net`'s page was reachable from the catalog and unreachable by paging:
  the previous/next links of the pages either side of it agreed with each
  other and skipped it. The docs link checker that found it ships as
  `tst/html-demo.shoddy`.

- The release scripts, corrected where they were actually wrong.
  `shoddy-release.sh` could never run under Git Bash — its repo-root guard
  compared two spellings of the same path.

## Notes for anyone reading the sources

Two properties of the runtime became load-bearing while this was written,
and both are documented where they bite:

- **File I/O is Latin-1** — one byte in the file is one character in the
  string, which is what lets the same words read a PNG. A character
  reference therefore has to decode to its **UTF-8 bytes**, not to
  `Chr(codepoint)`, or the same character written two ways is two
  different strings and `WriteFile` turns one of them into a question mark.
- **`Trim` strips spaces only** — not tabs, not newlines.
