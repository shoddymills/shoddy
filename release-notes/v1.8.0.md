A machine's top-level `Let` may bind a constant now, closing a restriction that
pushed every real constant into a zero-arg `Def` instead — and the retrofit
that follows it through the whole tree, machines, mills, the cave and the
tutorials alike. Also: a doc-review gate that would have caught v1.7.0's
encoding damage before it shipped, a test target that finally runs every
suite in the repo, and one finished rename.

## Machine constants are constants now

A machine has no `Run`, so it never had an init phase to assign a global in
— which is all the old refusal ever really said. `alg`, `eng` and `html` each
carried a table in the workaround shape, a zero-arg `Def` returning a fresh
list on every call: `Names() = Names()` was `False`, because a `List`
compares by identity, and `AlgFns()` rebuilt itself on every construction of
a function-call node, deep inside differentiation.

A constant needs no init phase. It's folded at compile time — literals, list
literals and type constructors to any depth, the arithmetic and concatenation
operators over constant operands, `ToArray`/`Dim` — and emitted once, as a
static field, beside the `TypeDef` fields a machine already builds that way.
Anything that isn't foldable is refused by name: a word call names the word,
not the feature, and a quotation gets its own message so `Map(xs, Upper)`
doesn't blame `Upper` for what `Map` did.

The binding stays private to its machine — a `Let` declares a value, not a
word, so nothing crosses the manifest and two machines may reuse the same
constant name. Publishing one is still a `Def` that returns it, which now
returns the *same* value every call. Details and the three new refusals are
on [`docs/spec.html`](https://shoddymills.github.io/shoddy/spec.html) and
[`docs/errors.html`](https://shoddymills.github.io/shoddy/errors.html).

## The retrofit

Nothing above required touching a mill — a top-level `Let` has always been
legal there, and the `Def`-as-constant idiom in mills was a habit the
*machine* restriction taught, not a requirement anywhere else. Once the habit
was worth breaking, it was broken everywhere it appeared:

- **Machines** — 67 constants across `eng` (44 unit and CODATA constants,
  plus the SI prefix list), `alg`, `html` and the rest. `EngConvert` stops
  allocating two records per call.
- **Mills** — 73 across seven mills: `devils-dust` (22, including its Knobs
  records), `pac-vt100` (17), `invaders` (11), `oregon` (11),
  `weather-glass` (7), `tally` (3), `iris` (2).
- **Mungo Caverns** — 233, the largest single case: `Messages`, a 213-entry
  string table indexed on every line the cave prints, was being rebuilt on
  every message. It's read as `Nth(messages, msgCaveNearby + 1)` now, built
  once. `Locations` (185 rooms), `Objects`, `Vocab`, `Travel` and the hint
  tables went the same way.
- **Tutorials and `tst`** — 13 more: the spiro tutorial's constants, the isam
  fixture, the neural test's weight vectors, the html/https demo values,
  shaker's demo key.

A survey script drives the retrofit and now reports `NO CONVERTIBLES
REMAIN` — that claim is machine-checked, not eyeballed. Anything that calls a
word rather than holding a plain value stayed a `Def`, everywhere; a table
built by concatenating other bindings is a computation, not a constant, and
is commented as such where it occurs. Every affected doc page that walks
code line by line — `docs/tutorials/first-mill.html` among them — was read
against the file it quotes, not just regenerated.

## Every suite runs now

The root test target ran `dotnet test`, six suites, and the spiro tutorial.
It skipped nine machine suites that already existed under `tst/`, and it
never ran a single mill's own suite, though eight mills carry one — v1.7.0
shipped through that gap. The gate now runs all of them.

## The encoding gate

`verify-docs.js` now refuses any tracked text file carrying UTF-8 that's
been round-tripped through CP1252 — the corruption that turns an em dash
into three characters, and on a second pass into eight. v1.7.0 shipped about
four hundred of them across eighteen files, the README's own section
headers included, and the old gate passed every one because it had no such
check. Both the gate and the repair ship together in this release.

## Emley Moor

The `rag-and-bone` mill is `emley-moor` now — the mast a few miles from
Huddersfield, whose entire job is taking a signal in and putting it back out
to whoever's listening, which describes an HTTP server rather better than a
man collecting rags. It gets its own icon instead of borrowing `https`'s
padlock. Separately, the `eng` machine's integral icon was being clipped by
four units at the bottom of its canvas since v1.7.0; redrawn inside its
bounds.
