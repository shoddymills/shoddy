Windows tooling cleanup, and a build that was quietly broken for anyone
running it outside Windows.

## Changed

- Every Windows-only `build.cmd` batch wrapper is gone, at the repo root
  and in every mill. The root wrapper's replacement, `build.ps1`, already
  existed and covers the same commands. Individual mills have no native
  Windows wrapper now — run their `build.sh` through Git Bash or WSL, the
  same as anywhere else it already worked.

## Fixed

- **`mills/devils-dust/build.sh` — and three more mills, plus both
  `scripts/shoddy-*.sh` — were committed without their executable bit.**
  Invisible on Windows, where NTFS has no such bit to check; fatal
  everywhere else, and what actually broke the last CI run
  (`Permission denied`, exit 126). All fixed. A new gate,
  `scripts/verify-permissions.js`, checks every tracked script for the
  same gap before every future release and fixes it automatically —
  running it once more turned up `build.ps1` and the two release
  scripts' own `.ps1` twins, which carry a `#!/usr/bin/env pwsh` shebang
  for cross-platform PowerShell Core and had the identical gap.
- Removing `build.cmd` uncovered two things that quietly depended on it
  existing: `src/Shoddy.Tests/RepoRoot.cs` used it to locate the repo
  root, so `dotnet test` would have failed to find the tree on every
  platform, not just Windows; and `build.ps1`'s own mill-test runner
  shelled out to each mill's `build.cmd` to run its suite. Both now use
  `build.sh` instead.

## Notes for anyone reading the sources

The pre-release doc review in `RELEASING.md` gained a third gate,
`scripts/verify-permissions.js`, alongside `verify-docs.js` and
`verify-errors.js`.
