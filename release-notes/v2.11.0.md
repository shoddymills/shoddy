## Added

**Mills**

- **thornle**, the five-letter guessing game in the terminal. Six
  guesses, each a whole typed line, and every letter marked in the
  project's three thread colours, or with `[A]` and `(A)` when colour is
  off. A numeric second argument seeds the game so a reported one can be
  replayed. The same game ships as `thornle.halifax`, so you can play it
  with Claude through sparky. See the
  [thornle page](https://shoddymills.github.io/shoddy/mills/thornle.html).

## Fixed

- **The capability lint sees what machine words reach.** It read only a
  machine's tag, and math carries none, so a mill that drew random numbers
  through `Pick`, `RandInt`, `RandRange` or `Chance` was told it used
  none. It now reads the body of each machine word a mill calls.
- **devils-dust and invaders declare `random`**, which both use. The
  Reckoner grants it to both.
- **Every shipped mill's manifest is checked against what the mill
  reaches**, in the golden suite, so a missing or unused capability fails
  the tests instead of shipping.
- **The errors page covers the capability lint, the manifest checks and
  the build gate** (`SHODDY1000` to `SHODDY1010`), and the check that
  every message is documented now reads the linter and the manifest code
  too.
