## Breaking

- **Two lists with the same items are now equal.** `{ 1, 2 } = { 1, 2 }`
  is True, and a record that holds a list compares all the way down. A
  function still compares by identity: two separately built functions are
  never equal. The one visible change in the library is `DictHas` and
  `DictPut` with list keys, which now treat two keys with the same contents
  as one key. `JEqual`, `XEqual`, `CsvEqual` and `CutEqual` stay.
- **Eight library words are builtins**: `Split`, `Join`, `Taken`, `DropN`,
  `ZipWith`, `Shuffle`, `Sample` and `DropAt`. Each keeps its name,
  arguments and machine page, and a program that defined a Def of one of
  those names is refused, as for any builtin. `Shuffle` and `Sample` need
  the `random` capability, as the machine words did.

## Added

- **Lists are cons cells.** `First`, `Rest` and `Prepend` are O(1) and share
  the tail; `Nth` on a list is O(1) after the first call on it; `SetNth`
  rebuilds only the cells before the change. A million-element walk, build
  or `Nth` loop runs in under a second. Nothing in a program has to convert
  a list to an array to index it, and no `ToArray` in the library exists for
  speed any more.
- **Strings are ropes.** `&` is O(1) and copies nothing; the text is laid
  down once, when the string is first read. `Len` never reads it. A fold
  that appends a million pieces runs in under a second.
- **Recursion has no practical limit.** Every launcher (`mill run`, `mill
  dap`, a woven program's own `Main`, `ShoddyHost.RunWovenAsync` and the
  perch) runs the program on a 1 GB stack, reserved rather than committed,
  so a non-tail recursion two million deep returns where about twenty
  thousand frames used to kill the process. Past that a stack overflow is
  still a process kill.
- **Any tail call is a jump.** A call in tail position to any Def in the
  program, not only to the Def itself, costs no stack, so mutual recursion
  runs flat. A tail call into a separately compiled machine stays a call.
- **`Select Case` takes a list apart.** `Case Empty` matches the empty list;
  `Case Prepend(head, tail)` matches a non-empty one and binds both, with
  `Where` guards and nesting as for records.
- The reckoner reaches `Taken`, `DropN`, `DropAt` and `ZipWith` through
  seedbuiltin; `Split`, `Join`, `Shuffle` and `Sample` were already seeded.
- `TryReadLines(path)`, a builtin: a text file as its lines, read natively
  one line at a time, answering `Ok(lines)` or the same `Err` as
  `TryReadFile`. `file.shoddy`'s `ReadLines` is now the aborting form over
  it, and the reckoner's `READLINES` is registered over it too.

## Changed

- The cost warnings are gone from the documentation and the library. The
  one statement of list and string cost is the pair of tables in section 7
  of the specification.
- **The grounding block in `docs/assistants.html` changed**, and so did the
  copy in `docs/tutorials/with-ai.html`. Re-copy these bullets into your
  `CLAUDE.md` and `.github/copilot-instructions.md`: the equality bullet
  (lists compare by their items; only functions by identity), the tail-call
  bullet (any tail call is a jump, mutual recursion included), the list
  bullet (lists are cons cells; recurse over them freely), the new `&`
  bullet, and the `Select Case` line in the house style (`Case Empty` and
  `Case Prepend`). The two bullets on `Rest` copying the tail and
  `Prepend` on the way out of a recursion are deleted.
- The documentation, error messages and lint messages are rewritten in
  plain language.
- The capability lint now reports a capability a `mill.manifest` declares
  but nothing in the mill reaches.

## Fixed

- `ReadLines` killed the process with a stack overflow on a file past about
  fourteen thousand lines: it split the whole text with `Split`, which
  recurses once per line. It reads natively now, so a file of any length
  loads.

- Two projects in one solution that embed the same Mode T mill could fail
  the build with MSB3246 ("bad image … being used by another process"):
  one project's weave rewrote the DLL while the other was reading it. The
  weave now writes beside and renames into place, and leaves identical
  output untouched.
- A build could hang indefinitely behind a stuck `mill` process. The mill
  now waits at most ten minutes for another mill working on the same
  target, then fails with a message naming it.
